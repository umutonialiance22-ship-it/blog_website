
# White cee— A Photography Journal

## About the Project

White cee is a responsive photography blog designed to celebrate
visual storytelling, landscapes, portraits, travel, and everyday life.

The website was created as an Advanced Frontend Web Development
assessment using HTML and Tailwind CSS.

## Features

- Responsive navigation
- Photography hero banner with a call-to-action link
- Six photography blog cards
- Category navigation links
- A full article page
- Article titles, categories, dates, and reading times
- Responsive layouts for mobile, tablet, and desktop
- Hover effects and accessible image descriptions
- About section and footer

## Technologies Used

- HTML5
- Tailwind CSS
- Google Fonts
- Unsplash images

## How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Make sure you have an internet connection for Tailwind CDN,
   Google Fonts, and remote images.

## Tailwind CSS

Tailwind CSS utility classes are used directly in the HTML markup.

Examples:

- `bg-stone-50` sets a light stone background.
- `max-w-7xl` limits the maximum content width.
- `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3`
  creates a responsive three-column blog layout on large screens.
- `px-6 py-5` adds horizontal and vertical padding.
- `rounded-2xl` rounds the corners.
- `hover:shadow-xl` adds a larger shadow when the user hovers.
- `transition duration-500` animates supported visual changes.
- `text-stone-600` changes the text color.
- `focus-visible:outline` helps make keyboard focus visible.

## Responsive Design

The website uses Tailwind's responsive prefixes:

- `sm:` applies styles at small-screen breakpoints and above.
- `md:` applies styles at medium-screen breakpoints and above.
- `lg:` applies styles at large-screen breakpoints and above.

For example, the blog cards use one column on small screens,
two columns on medium screens, and three columns on large screens.
